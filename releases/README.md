# Право Некс — личная CRM для Android

[Скачать актуальную версию 0.3.0](https://github.com/romanlapshin0-lang/Pravoneks.app/raw/refs/heads/main/releases/Pravo-Nex-0.3.0.apk)

Около 2,1 МБ. Android 8.0 и новее. Один пользователь, все разделы доступны без ролей сотрудников. Прежняя база сохраняется при обновлении. Сертификат и идентификатор приложения прежние; удалять установленную версию не нужно.

## Как импортировать клиента из ChatGPT

1. В Android передайте текст или общедоступную ссылку через «Поделиться» → «Право Некс». Либо скопируйте сообщение в ChatGPT и откройте CRM → «Клиенты» → «Импорт из ChatGPT» → «Вставить».
2. Для текста нажмите «Разобрать текст», для ссылки — «Загрузить по ссылке ChatGPT».
3. Проверьте черновик: имя, телефон, почту, суть, направление и стоимость, если она согласована.
4. Выберите, что сохранить: только клиента, клиента с заявкой, клиента с делом или клиента с делом и обычной задачей. По умолчанию создается только клиент.
5. Нажмите «Сохранить». Откроется карточка клиента со связанными записями.

Поддерживаются общедоступные ссылки `https://chatgpt.com/share/…`. Закрытая ссылка `/c/…` не предоставляет приложению доступ к вашему аккаунту: передайте текст нужного сообщения. Если сайт не отдает текст прямому запросу, можно открыть общедоступную страницу внутри приложения и нажать «Импортировать сообщения». Доступность конкретной страницы зависит от ChatGPT, сети телефона и Android System WebView. Проверка именно предоставленной пользователем живой ссылки в облачной среде была заблокирована сетевой политикой; успешная загрузка этой страницы не заявляется.

Передача текста не требует публикации чата. Общедоступная ссылка ChatGPT может открывать переписку другим людям — учитывайте это до ее создания.

## Что еще изменено

- Отдельные карточки клиентов с контактами, редактированием и исходным обращением.
- Создание заявки, дела или задачи по выбору, без автоматического подтверждения процессуальных сроков.
- Защита от повторного импорта одинакового текста или ссылки.
- Очередь входящих обращений сохраняет незавершенную форму.
- Экспорт CSV по клиентам, заявкам, делам или задачам.
- Стоимость можно согласовать позже; цена не может стать ниже уже полученных платежей.
- Защита входа, шифрование, журнал и зашифрованные копии остаются. Файловые операции выполняются в фоне.

## Установка

Скачайте именно `Pravo-Nex-0.3.0.apk`, откройте на телефоне через «Файлы» → «Загрузки» и выберите «Установить». При скачивании на компьютер перенесите APK на телефон по USB. Установка поверх прежней версии сохраняет базу. Перед обновлением важных данных полезно иметь зашифрованную резервную копию.

41 автоматический тест прошел без ошибок и пропусков; Android Lint без ошибок. APK проверен по целостности, наличию исполняемого кода, подписи и выравниванию. Обновление 0.3 и прием текста через ACTION_SEND проверены в Android-эмуляторе. Это не испытание на конкретном Realme.

Новое приложение начинает с пустой базы; прежние записи при обновлении не очищаются. Резервные копии создаются вручную с отдельным паролем.
