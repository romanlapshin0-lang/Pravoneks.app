# Право Некс для Android

[Скачать актуальную версию 0.2.0](https://github.com/romanlapshin0-lang/Pravoneks.app/raw/refs/heads/main/releases/Pravo-Nex-0.2.0-demo.apk)

Размер: около 2 МБ. Требуется Android 8.0 или новее. Это оптимизированная демонстрационная сборка на вымышленных данных.

## Установка

1. Скачайте именно файл **Pravo-Nex-0.2.0-demo.apk**.
2. Откройте его на телефоне через «Файлы» → «Загрузки». Если скачали на компьютер, сначала перенесите APK на телефон по USB.
3. Разрешите установку из текущего источника при запросе Android и нажмите «Установить».

Сертификат и идентификатор приложения сохранены: ранее установленная версия обновляется поверх с сохранением данных. Не удаляйте установленное приложение с нужными данными без резервной копии.

## Что улучшено

- APK уменьшен с 18 до примерно 2 МБ; удален неиспользуемый код и ресурсы.
- Важные сроки и ближайшие задачи подняты выше финансов.
- Увеличены подписи и зоны нажатия.
- Заголовок формы остается видимым при прокрутке, ошибки показываются отдельно.
- Текст формы сохраняется при повороте экрана; закрытие измененной формы требует подтверждения.
- Для выполнения задачи добавлена отмена; кнопка «Назад» возвращает к предыдущему уровню.
- Загрузка защищенных данных выполняется в фоне с понятным индикатором.

## Что проверено

17 тестов без ошибок и пропусков, Android Lint без ошибок. Проверены содержимое DEX, подпись, выравнивание и контрольная сумма APK. Окончательная версия успешно установлена Android Package Manager на эмуляторе Android 9 (около 10–15 секунд), первый запуск завершился `Status: ok`. Эмулятор не воспроизводит оболочку Realme. Причина зависания прежней установки на Realme 14 Pro+ не установлена.

Если установка новой версии снова не заканчивается, отмените ее и сохраните снимок именно окна установщика или текст ошибки. Не отключайте защиту Android.
