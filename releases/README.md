# Право Некс — личная CRM для Android

[Скачать актуальную версию 0.4.0](https://github.com/romanlapshin0-lang/Pravoneks.app/raw/refs/heads/main/releases/Pravo-Nex-0.4.0.apk)

Около 2,1 МБ. Android 8.0 и новее. Один пользователь, без ролей сотрудников. Устанавливайте поверх прежней версии: сертификат и идентификатор приложения сохранены, база не очищается. Удалять приложение для обновления не нужно. Для важных данных заранее создайте зашифрованную резервную копию.

## Самый удобный способ перенести клиента из ChatGPT

1. В CRM откройте «Клиенты» → «Импорт из ChatGPT» → **«Скопировать запрос для ChatGPT»**.
2. Вставьте запрос в нужную переписку ChatGPT. Он попросит подготовить файл **«Клиент.json»** со сведениями об одном клиенте, сути обращения и задачах.
3. Скачайте файл. Передайте его через Android «Открыть с помощью» / «Поделиться» → «Право Некс» или выберите внутри CRM кнопкой **«Выбрать файл клиента»**.
4. Проверьте поля. По умолчанию создается только клиент. Дополнительно можно выбрать заявку, дело или дело с задачами. Выберите нужные задачи и уточните даты.
5. Нажмите **«Сохранить»**. Кнопка закреплена внизу экрана; откроется карточка клиента.

Если ChatGPT не прикладывает файл, скопируйте выданный JSON и нажмите «Вставить» в CRM. Обычный TXT в UTF-8 и текст сообщения тоже поддерживаются. Передавать полный чат или публиковать общедоступную ссылку не требуется. Файловый импорт работает без доступа к сайту ChatGPT и не отправляет базу в нейросеть.

## Как проверяются данные

- Неизвестные поля остаются пустыми. Сумма иска или долга не является стоимостью юридической услуги.
- При импорте файла не выполняются команды, не добавляются платежи и не подтверждаются процессуальные сроки.
- До 20 задач из файла доступны для выбора. Обычные задачи с датой предварительно выбраны внутри режима с задачами. Процессуальные задачи и задачи без даты предварительно выключены. Выбранной задаче нужна дата.
- Процессуальная задача после импорта остается неподтвержденной. Ее срок проверяется и подтверждается отдельно в разделе «Задачи».
- Повтор одинакового JSON блокируется независимо от отступов и порядка ключей. При похожих имени или контактах показывается предупреждение; карточки не объединяются автоматически.
- Ошибка файла не меняет базу и не заменяет предыдущий черновик. Незавершенная форма защищена очередью входящих обращений.
- Лимиты: 50 000 символов и 200 000 байт UTF-8. Неверная структура, неподдерживаемая версия, поврежденная кодировка и неподходящий двоичный формат показывают ошибку.

Приложение переносит подготовленные поля, но не устанавливает истинность ответа ChatGPT. Перед сохранением проверьте имя клиента, контакты, обстоятельства, цену и сроки. JSON/TXT не зашифрованы сами по себе — учитывайте это при хранении скачанного файла.

## Другие возможности

Клиенты, заявки, дела, задачи, финансы, DOCX, аналитика, журнал изменений, CSV и зашифрованные резервные копии. Новая установка начинается с пустой базы, существующие записи сохраняются при обновлении. Встроенные DOCX-шаблоны демонстрационные, перед подписанием требуют юридического утверждения. Соответствие 152-ФЗ не заявляется.

В дополнительном разделе «Импорт по ссылке ChatGPT» сохранены общедоступные ссылки `https://chatgpt.com/share/…`. Закрытые `/c/…` не предоставляют доступ к аккаунту. Если сайт не отдает текст, предусмотрено открытие общей страницы внутри приложения. Доступность зависит от ChatGPT, сети и Android System WebView. Предоставленная пользователем живая ссылка в облачной среде не проверена из-за сетевой политики; успешная загрузка конкретной страницы не заявляется.

## Установка

Скачайте `Pravo-Nex-0.4.0.apk`, откройте на телефоне через «Файлы» → «Загрузки» и выберите «Установить». При скачивании на компьютер перенесите APK на телефон по USB. Если файловый менеджер не предлагает открыть клиентский JSON в CRM, используйте кнопку выбора файла внутри приложения.

58 автоматических тестов прошли без ошибок и пропусков; Android Lint — без ошибок. Проверены целостность APK, DEX, подпись и выравнивание. SHA-256 указан в `SHA256SUMS.txt`. Физический Realme для проверки недоступен; результаты автоматических UI-тестов не являются испытанием на этом телефоне.
