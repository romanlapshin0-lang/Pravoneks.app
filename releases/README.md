# Право Некс — начать работу с пустой базы

[Скачать версию 0.4.1 «Чистый старт»](https://github.com/romanlapshin0-lang/Pravoneks.app/raw/refs/heads/main/releases/Pravo-Nex-0.4.1-clean.apk)

**При первом запуске эта версия однократно очищает прежнюю базу приложения:** клиентов, заявки, дела, задачи, платежи, записи созданных документов и журнал. Доходы, задолженность и аналитика начинаются с нуля. Эта очистка подготовлена по запросу владельца перед внесением первого клиента.

Установите APK поверх прежней версии и откройте приложение. Удалять приложение вручную не нужно. На главном экране появится **«Добавить первого клиента»**. Последующие запуски уже не очищают базу: новые клиенты и вся дальнейшая работа сохраняются.

Около 2,1 МБ. Android 8.0 и новее. Сертификат и идентификатор приложения прежние. Сохраняются имя исполнителя, настройки защиты, все функции и встроенные шаблоны. Демонстрационная база больше не включается в APK.

Ранее экспортированные файлы и резервные копии в папках телефона не удаляются и автоматически не загружаются. Если нужна прежняя база, сначала сохраните ее в зашифрованную копию, до открытия этой версии.

## Импорт первого клиента из ChatGPT

1. «Клиенты» → «Импорт из ChatGPT» → **«Скопировать запрос для ChatGPT»**.
2. Вставьте запрос в нужную переписку и скачайте файл «Клиент.json».
3. **«Выбрать файл клиента»**, либо Android «Открыть с помощью» / «Поделиться» → «Право Некс».
4. Проверьте карточку, выберите клиента, заявку, дело или дело с задачами и нажмите **«Сохранить»**.

Можно вставить JSON текстом или выбрать обычный TXT. Интернет для чтения файла не нужен. Неизвестные даты остаются пустыми, процессуальные сроки подтверждаются отдельно. Один импорт — один клиент; все поля нужно проверить перед сохранением.

## Защита и документы

Локальное шифрование, защита входа, журнал, CSV и зашифрованные копии сохранены. Встроенные DOCX-шаблоны остаются демонстрационными и требуют юридического утверждения перед подписанием. Промышленное соответствие 152-ФЗ не заявляется.

66 автоматических тестов прошли без ошибок и пропусков. Android Lint — без ошибок. Проверены ZIP CRC, DEX, подпись и выравнивание APK; сертификат совпадает с 0.4.0. SHA-256 указан в `SHA256SUMS.txt`. Испытание на физическом Realme не проводилось.
